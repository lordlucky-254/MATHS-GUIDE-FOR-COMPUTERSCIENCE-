# Contributing to CS-Math-Essentials

Thank you for helping make Computer Science mathematics more accessible and practical for students everywhere!

## Ways to Contribute
1. **Add Free Learning Resources:** Textbooks, university lecture notes, interactive visualizers, or video series.
2. **Add Code Implementations (`code/`):** Clean, well-commented Python scripts illustrating mathematical algorithms or concepts.
3. **Expand Cheat Sheets (`cheatsheets/`):** Add key theorems, intuition notes, or CS use cases.
4. **Add Practice Problems (`exercises/`):** Include clear problem statements and step-by-step solutions inside `<details>` blocks.

## Pull Request Process
1. Fork the repository and create your branch (`git checkout -b feat/add-topic`).
2. Verify that any Python scripts in `code/` run cleanly with standard Python 3 (`python3 code/your_script.py`).
3. Ensure LaTeX math blocks use `$inline$` and `$$display$$` syntax compatible with GitHub Markdown.
4. Submit a Pull Request with a concise summary of your additions.
